# Authors and acknowledgements

This documentation and codebase are currently maintained by [Philip Brohan](https://brohan.org/) (Met Office).

All errors are the responsibility of the maintainer; credit is widely shared.

While the human maintainer is entirely responsible for the project, almost all the work was done by AI: [GitHub Copilot](https://github.com/features/copilot) wrote all the code and almost all the documentation. The transcriptions were done by five small VLMs:

- [Huggingface SmolVLM2 2.2B](https://huggingface.co/HuggingFaceTB/SmolVLM2-2.2B-Instruct)
- [IBM Granite vision 4.1-4b](https://huggingface.co/ibm-granite/granite-vision-4.1-4b)
- [Google Gemma 3 4b](https://huggingface.co/google/gemma-3-4b-it)
- [Google Gemma 4 E4B](https://huggingface.co/google/gemma-4-E4B)
- [Mistral-Small-3.1-24B](https://huggingface.co/mistralai/Mistral-Small-3.1-24B-Instruct-2503)

All of which were downloaded from [Huggingface](https://huggingface.co/).

- This project was created by Philip Brohan (philip.brohan @ metoffice.gov.uk). He was funded by the Met Office Hadley Centre Climate Programme funded by BEIS, and by the Met Office Weather and Climate Science for Service Partnership (WCSSP) South Africa as part of the Newton Fund.
- This project is a follow-on to [Rainfall Rescue](https://brohan.org/Robot_Rainfall_Rescue/), which established the general method.
- This project's outputs are used by [Auto daily Rainfall QC](https://brohan.org/Auto-Daily-Rainfall-QC/) which turns the raw transcriptions into ready-to-use observations.
- [The document images used](https://digital.nmla.metoffice.gov.uk/SO_51194883-b9dd-4e27-93db-958f8fbea38b/) were provided by the [Met Office Digital Library and Archive](https://digital.nmla.metoffice.gov.uk/) imaged from the collection of the [National Meteorological Library and Archive](https://www.metoffice.gov.uk/research/library-and-archive). The original documents exist because of the efforts of thousands of observers, scientists, archivists and administrators over many years.
- The validation sample of 75 images+transcriptions (from Irish Daily Rainfall records) was provided by Ciara Ryan.
